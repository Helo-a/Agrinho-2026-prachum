# Agrinho-2026-prachum
O site acima (AgroVerde) é de caráter informativo, com foco em discorrer sobre biotecnologia, bioinsumos, sustentabilidade e impactos sociais do agronegócio, trazendo dados e informações reais.
Foram utilizadas as linguagens HTML, CSS e JAVASCRIPT para a formação do site, sendo também utilizada inteligência artificial(gemini).
A página é constituída por atalhos objetivos para as informações desejadas, um gráfico informativo de grande escala sobre "Comparação entre Defensivos Químicos e Biológicos", um teste de conhecimentos, o qual estimula a busca pela informação; e um pequeno glossário com simples informações do que se inclui no tema do site.
